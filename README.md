# Mini SPA Project

This is my Mini Single-Page Application (SPA) project for Web Technologies.

## Features
- Home, About and Services pages
- Navigation buttons to switch between sections
- JavaScript changes sections without reloading the page
- Header, navigation, content sections, and footer

# Components
- Header: Displays the website title.
- Navigation: Contains the Home, About, and Services buttons.
- Main Content: Didplays the Home, About, and Services sections.
- Footer: Didplays the copyright information.

## How to Run the Project
1. Open the Mini-SPA-Project in VS Code.
2. Open index.html using Live Server.
3. Click the Home, About, or Services buttons to switch sections.
